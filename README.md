EN CRIOLLO 

ABRIR EL SITIO

Doble clic en index.html. Se abre en tu navegador. No necesita internet
ni instalar nada (funciona 100% offline, ni siquiera usa fuentes de Google).


PÁGINAS

🏠 Inicio       — resumen: próximo vencimiento, tareas, balance del mes
🗓️ Calendario   — vencimientos automáticos + tus propios eventos
✅ Tareas        — lista con categoría y fecha opcional
💰 Mi plata      — ingresos y gastos, mes a mes
🧾 Impuestos     — guía + calculadoras (Monotributo, Ganancias, IVA, Bienes Personales)
❓ Ayuda         — backup y explicación de privacidad
⚙️ admin.html    — editar tus datos en crudo (no está en el menú, es para casos raros)


DÓNDE QUEDAN TUS DATOS

En tu navegador, en tu compu. Nadie más los ve, no se suben a ningún lado.
Si tenés el sitio abierto en DOS PESTAÑAS del mismo navegador, se
sincronizan solas: cambiás algo en una y la otra se actualiza sin que
hagas nada.

Entre DISPOSITIVOS distintos (o navegadores distintos) no se sincroniza
solo — para eso usá Ayuda → Descargar copia de seguridad, y después
Ayuda → Importar en el otro dispositivo.


ACTUALIZAR MONTOS DE IMPUESTOS (cada 6 meses)

Abrí data.js con el Bloc de Notas. Cambiá solo los números.
Fuente oficial: https://www.arca.gob.ar


SI ALGO NO FUNCIONA

1. Probá otro navegador (Chrome, Firefox, Edge)
2. F12 → pestaña "Console" → mandame el error en rojo si hay uno
3. Si los datos se ven raros, admin.html te deja ver/arreglar el JSON a mano
4. Como último recurso: Ayuda → Borrar todo (o admin.html → Zona de peligro)

Te queremos. 🇦🇷
